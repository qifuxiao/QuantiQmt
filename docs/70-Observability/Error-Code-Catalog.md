# Error Code Catalog

> Status: Proposed  
> 错误码稳定且机器可读，错误消息可演进。不得直接把供应商错误码作为系统 error_code。

格式：`QQ-{DOMAIN}-{NUMBER}`。数字段保留兼容人类分组；日志同时记录 category、retryability 和 raw_error_code。

| 范围 | Domain |
|---|---|
| 1000–1999 | COMMON |
| 2000–2999 | MARKET |
| 3000–3999 | STRATEGY |
| 4000–4999 | RISK |
| 5000–5999 | OMS |
| 6000–6999 | EXECUTION/BROKER |
| 7000–7999 | STORAGE/MESSAGING |
| 8000–8999 | RECOVERY/RECONCILIATION |
| 9000–9999 | CONFIG/SECURITY/OPERATIONS |

## 治理规则

- 已发布 code 不复用、不改变含义；废弃后保留登记。
- 新错误先判断能否复用 category/code，避免为每个供应商错误创建系统码。
- UNKNOWN_OUTCOME 绝不能标成普通 TRANSIENT 后自动重试外部副作用。
- API 返回 error_code、safe message、correlation_id；内部 details 和 raw message 不暴露敏感信息。
